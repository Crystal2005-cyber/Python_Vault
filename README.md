Python Vault: CLI Automated ATM & Bank Account Simulator

Project Type: Python CLI Application
Team Size: 2 Members
Domain: Banking / Financial Simulation
Language: Python

Project Overview

Python Vault is a command-line banking and ATM simulation system developed in Python. It allows users to create and manage bank accounts, securely log in using account credentials/PIN, check balances, deposit and withdraw money, transfer funds, and view transaction history.

Main Features
Account Creation
Create a new bank account
Generate/store account number
Set a secure PIN
User Authentication
Account number + PIN login
Limited login attempts
Basic security validation
ATM Operations
Check balance
Deposit money
Withdraw money
Transfer money
Change PIN
Transaction Management
Record deposits and withdrawals
Maintain transaction history
Display transaction details
Input Validation
Prevent invalid amounts
Prevent withdrawal beyond available balance
Handle incorrect account numbers/PINs
Handle invalid menu selections
Data Storage
Store account information using files such as JSON/CSV
Preserve data after the program closes
