# 🏦 Python Vault: CLI Automated ATM & Bank Account Simulator

## 📌 Project Overview

**Python Vault** is a command-line-based Automated Teller Machine (ATM) and Bank Account Simulator developed using Python.

The project simulates basic banking operations through a simple CLI interface. Users can create bank accounts, securely log in using their account number and PIN, check their balance, deposit and withdraw money, transfer funds, view transaction history, and change their PIN.

The project demonstrates important Python programming concepts such as **Object-Oriented Programming, functions, file handling, JSON data storage, exception handling, loops, conditional statements, and input validation**.

---

## 🎯 Problem Statement

Traditional banking systems are complex and require sophisticated infrastructure. For learning purposes, students need a simple system that demonstrates how basic banking and ATM operations work.

The objective of **Python Vault** is to develop a Python-based CLI application that simulates common banking operations while maintaining account and transaction information using local data storage.

---

## 🎯 Objectives

* To develop a simple CLI-based banking system.
* To allow users to create and manage bank accounts.
* To implement account authentication using account number and PIN.
* To provide basic ATM operations.
* To maintain transaction history.
* To store account information persistently using JSON.
* To implement input validation and exception handling.
* To demonstrate Object-Oriented Programming concepts in Python.

## ✨ Features

### 👤 Account Management

* Create a new bank account.
* Automatically generate a unique account number.
* Set a 4-digit PIN.
* Maintain account holder information.
* Store account balance.

### 🔐 Authentication

* Login using account number and PIN.
* Allow a maximum of three login attempts.
* Prevent unauthorized access to ATM operations.

### 🏧 ATM Operations

* Check account balance.
* Deposit money.
* Withdraw money.
* Transfer money to another account.
* View transaction history.
* Change PIN.
* Logout.

### 💰 Transaction Management

The system records:

* Deposits
* Withdrawals
* Transfers
* Account opening deposits
* Transaction date and time
* Balance after each transaction

### 💾 Data Persistence

Account information is stored locally in a **JSON file**.

The JSON file is automatically created by the program when the first account is saved.

## 🖥️ How to Use

When the program starts, the main menu appears:

```text
==================================================
             PYTHON VAULT
      CLI ATM & BANK SIMULATOR
==================================================

1. Create Account
2. Login
3. Exit

Enter your choice:
```

### 1. Create Account

Select:

```text
1
```

Enter:

* Full name
* 4-digit PIN
* Initial deposit

Example:

```text
Enter your full name: Suchanda
Create a 4-digit PIN: 1234
Enter amount: ₹5000
```

The system generates an account number automatically.

Example:

```text
Account created successfully!
Account Holder : Suchanda
Account Number : 100001
Initial Balance: ₹5000.00
```

---

### 2. Login

Select:

```text
2
```

Enter the account number and PIN.

Example:

```text
Enter account number: 100001
Enter 4-digit PIN: 1234
```

After successful authentication, the ATM menu is displayed.

## 🏧 ATM Menu

```text
==================================================
                 ATM MENU
==================================================
1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Transfer Money
5. Transaction History
6. Change PIN
7. Logout

Enter your choice:
```

### Check Balance

Displays the user's current account balance.

### Deposit Money

Adds money to the account.

Example:

```text
Enter amount: ₹2000
₹2000.00 deposited successfully.
```

### Withdraw Money

Allows the user to withdraw money if sufficient balance is available.

Example:

```text
Enter amount: ₹1000
₹1000.00 withdrawn successfully.
```

The system prevents withdrawals greater than the available balance.

### Transfer Money

Allows money to be transferred between two registered accounts.

Example:

```text
Enter receiver account number: 100002
Enter amount: ₹500
₹500.00 transferred successfully.
```

### Transaction History

Displays previous transactions along with:

* Transaction type
* Amount
* Date and time
* Account balance

### Change PIN

Allows the user to change their existing 4-digit PIN after entering the current PIN.

### Logout

Logs the current user out and returns to the main menu.

## 🗃️ JSON Data Storage

The project uses JSON for persistent storage.

Example:

```json
{
    "accounts": {
        "100001": {
            "name": "Suchanda",
            "pin": "1234",
            "balance": 5000.0,
            "transactions": []
        }
    }
}
```

Whenever an account is created or a transaction occurs, the JSON file is updated.

This allows account data to remain available even after the program is closed.

## 🔒 Security Note

This project is an **educational banking simulator** and is not intended for real financial transactions.

For a production banking application, sensitive information such as PINs must not be stored as plain text. Proper encryption/hashing, secure authentication, authorization, database security, and audit mechanisms would be required.
